🤖 Sarcasm Detector

Sarcasm Detector is a Kotlin-based Android application that uses the Naive Bayes machine learning algorithm to analyze user-provided text and classify whether it contains sarcastic content. The application performs on-device text classification and probability-based prediction, delivering real-time results without requiring a backend or external API.

✨ Key Features

* 🤖 Sarcasm detection using Naive Bayes
* 📝 User-provided text analysis
* 🧠 On-device machine learning
* 📊 Probability-based text classification
* ⚡ Real-time prediction results
* 🔒 Offline processing without a backend
* 🧹 Text preprocessing and feature extraction
* 📱 Native Android implementation

🏗️ Architecture & Workflow

The application receives text input through the Android UI and preprocesses it before passing it to the Naive Bayes classifier. The classifier evaluates the probability of the text being sarcastic and returns the prediction, which is then displayed to the user in real time.

🛠️ Tech Stack

Kotlin • Android • Machine Learning • Naive Bayes • Text Classification • Probability-Based Prediction

🎯 Project Purpose

This project demonstrates how a traditional machine learning algorithm can be integrated into a native Android application for on-device text classification. It provides practical experience with text preprocessing, feature extraction, probability-based prediction, and implementing an offline ML workflow without relying on a backend.
